# Marketing Campaign Performance Dashboard

An interactive Power BI report analysing campaign performance for three
brands (Nykaa, Purplle, Tira) across about 167K campaign records,
Jul 2024 to Jun 2025.

## Files
- `Marketing_Campaign_Dashboard.pbix` : the Power BI report (3 pages:
  Overview, Performance, Funnel)
- `Marketing_Campaign_Power_BI_Project_Report.docx` : the full project
  report covering data cleaning, the data model, DAX measures, dashboard
  development, case studies and conclusions

## Highlights
- Data prepared in Power Query and modelled as a star schema with a
  bridge table and a DAX date table
- 19 DAX measures and 12 KPIs across 3 interactive pages
- Slicers, drill-through, conditional formatting and page navigation

## Dataset
Multi-Brand Marketing Campaign Performance Dataset (Kaggle):
https://www.kaggle.com/datasets/sshriya08/multi-brand-marketing-campaign-performance-dataset/data

## Tools
Power BI Desktop, Power Query, DAX

## How to open
Download the `.pbix` file and open it in Power BI Desktop. The report shows
the data saved in it. To refresh, point the data source to the downloaded
Kaggle CSV files (Home → Transform data → Data source settings).
